# ToM+ Documentation Website

This is a zero-build static website generated from `index.md`. Upload the contents of this folder to Cloudflare Pages.

## Important: images
The generated HTML keeps the original relative paths such as `figures/dashboard.jpg` and `icons/BatterySoc.jpg`. Copy the original `figures/` and `icons/` folders next to `index.html` before deploying.

No server-side code or build command is required.
